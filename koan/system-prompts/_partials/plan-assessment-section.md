### Plan Assessment

Exactly one line of plain markdown — not wrapped in backticks or a code block — in this format:

**Complexity:** S|M|L · **Risk:** Low|Medium|High · **Why:** one clause

Complexity reflects the amount of work; risk reflects what breaks if the plan turns out to be wrong — blast radius, reversibility, data loss. Keep the `Why` to a single clause naming the main driver. No bullet list, no second line.
